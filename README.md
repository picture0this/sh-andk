# لعبة شعندك؟ 🎉

لعبة جماعية على شاشة واحدة — فريقان يتنافسان بجمع النقاط.

## طريقة التشغيل
افتح ملف `index.html` بأي متصفح (كروم، إيدج...). ما تحتاج سيرفر ولا إنترنت للواجهة —
الإنترنت يحتاجه فقط تلفون اللاعب لما يصوّر الباركود ويفتح الصورة.

## طريقة اللعب
1. كل فريق يكتب اسمه فوق (ما يتغير أثناء الجولة).
2. اختر **خمن الصورة** ثم فئة فرعية (سيارات، منتجات، دول العالم...).
3. يطلع باركود للفريق الأول — يصوّره بتلفونه ويشوف الصورة، ثم Next، وبعده باركود الفريق الثاني.
4. يبدأ عدّاد 30 ثانية: كل فريق يسأل عن صورة الفريق الثاني ويحاول يخمنها.
   - ↺ إعادة العدّاد، ⏸ إيقاف مؤقت، ✔ إذا انخمنت الصورة.
5. تطلع البطاقتان مع اسم كل فريق للتأكد — اضغط **?Winner** تحت الفريق الفائز
   وينضاف له 100 نقطة تلقائياً ويرجع للرئيسية.
6. أول فريق يوصل **نقاط الفوز** (1200 افتراضياً، تقدر تغيّرها من الرئيسية) يفوز! 🏆

- أزرار **+ / −** جنب النقاط لتصحيح أي خطأ (زيادة أو نقص 100).
- النقاط والأسماء تنحفظ تلقائياً حتى لو سكّرت الصفحة.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | هيكل الصفحة والشاشات |
| `style.css` | التصميم والألوان |
| `script.js` | منطق اللعبة (الجولات، العدّاد، النقاط) |
| `data.js` | **الفئات والبطاقات — عدّل هنا لإضافة صور وفئات** |
| `assets/` | صور الفئات وشعار الكلية |
| `vendor/qrcode.min.js` | مكتبة توليد الباركود (محلية) |
| `fonts/` | الخطوط العربية (محلية — تشتغل بدون إنترنت) |

## إضافة بطاقات جديدة
افتح `data.js` وأضف عنصراً داخل الفئة:
```js
{ name: "اسم البطاقة", url: gimg("كلمات البحث بالصور") }
```
أو حط رابط صورة مباشر بدل `gimg(...)`.

الفئات `سؤال و جواب`، `ولا كلمة`، `خلك صريح` والبطاقتان `؟؟؟` — للمستقبل، حالياً شكلية فقط.
